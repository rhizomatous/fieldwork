# Fieldwork

This project is a tech demo of a full agentic development environment running locally within the browser.

## Rules

- Use Nix for all developer tooling.
- Use TypeScript for all files.
- Use the Fieldwork design system in `./src/design-system` for all UI. If you build a component that's shared between many places, extract it into the system.
- Extract any content shared content between different top-level folders in to `./shared/`
- Do not add irrelevant context to README.md. This document should only contain introductory information about the project's purpose, setup, and usage.
- Run the checks before completing your work. Address any failures that arise.
- Check significant changes in a live browser.
